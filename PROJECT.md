# PROJECT.md — WePlay-KZ

Kazakhstan-localized AI party game web platform. Looks like a multiplayer party platform but runs entirely with local AI agents for singleplayer gaming.

## Tech Stack
- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- framer-motion
- Google Gemini (gemini-1.5-flash fallback or gemini-2.0-flash)
- localStorage for persistence
